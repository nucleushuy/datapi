    Supported formats and limits

    CSV: UTF-8 (BOM allowed), comma-separated, with unique nonempty column names in the first row. Double-quoted fields may contain commas or line breaks; every row must have the same number of fields. A header-only file is valid. Empty strings, whitespace, and leading zeros are preserved.

    Parquet: A valid, unencrypted .parquet file. Native types are shown alongside basic types. Preview values use DuckDB text; integers and decimals retain their exact text, and nested values are explicitly labeled. Null and empty string are distinct.

    Up to 100 MB (100,000,000 bytes) per file, 512 columns, 1 MiB per record, and 256 MiB decoded data. Parquet metadata: 16 MiB footer and 64 MiB uncompressed row group. Processing: 1 GiB worker memory, 512 MiB temporary disk, and 5 minutes. Preview: up to 500 rows and 8 MiB per page; wide rows may produce shorter pages. File extension, MIME hint, and content must agree; unsupported or oversized files are rejected, never sampled silently.
